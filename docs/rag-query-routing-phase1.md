# 查询意图识别：检索决策边界

## 本次修改

当前分析查询只负责判断用户消息是否需要进入企业知识库检索，不负责查询重写、选库、权限判断或回答问题。需要检索时进入一个查询重写节点，由该节点同时完成语义查询改写和全文关键词扩展，检索阶段保留并行使用原始问题。

路由 LLM 只接收当前消息和必要的对话上下文，不再接收知识库名称、描述、ID、权限范围或可用性信息。模型不判断知识库是否有内容，只根据问题本身判断是否值得检索。

当模型判定不需要检索时，必须输出简短 `reason`。该原因只能说明消息属于问候、闲聊、通用创作、整理已有内容等非检索类型，不能说明知识库没有内容，也不能回答用户问题。

知识库目录、授权范围等确定性路径仍由后端硬规则处理；硬规则使用的授权知识库元数据不会传给路由 LLM。

查询重写节点内部使用两份独立提示词：一份只生成适合向量检索的独立查询，另一份只生成全文检索短关键词。向量检索分别使用原文和语义改写，全文检索使用原文和关键词扩展；该节点不接收知识库元数据。
